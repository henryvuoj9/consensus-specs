# SSZ, static tests

Bộ test-suite này cung cấp kiểm thử tĩnh (static) cho SSZ: chỉ đơn giản là khởi
tạo các kiểu SSZ đã biết của Ethereum từ dữ liệu nhị phân.

Loạt test này dựa trên file `eth_consensus_specs/utils/ssz/ssz_impl.py` do spec
duy trì, tức là hoàn toàn nhất quán với SSZ spec.

Tài liệu về test format có tại đây: [core test format](./core.md).
